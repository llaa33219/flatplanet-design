10 — Overlay

Modals, Drawers & Disclosure

Overlays use the same shell as cards — 36 px radius, hard shadow, solid scrim.

What is the 36px radius rule?
36 px is the ceiling for corner rounding across the entire system. Radii below 36 px are allowed only where the component's height makes a 36 px radius physically impossible to read — for example a 36 px-tall badge or a 28 px-tall chip.
How does the hover press work?
A main element's shadow starts at height H. On hover the shadow collapses to 2 px and the element descends by H − 2 px, so the shadow's absolute bottom edge never moves. Sub elements do the opposite: they rise by the sub-shadow height and gain that shadow at the same time.
Which way can a shadow fall?
Only to the bottom-right. Every shadow is (positive px) (positive px) 0 <ink> — positive offsets, equal on both axes, zero blur, zero spread. There is no upward shadow, no leftward shadow, and no band on all four sides: a band is a border, not a shadow. If you want a different look, change the shadow's size, not its direction.
Are gradients really banned?
Yes — no component uses a gradient anywhere. Depth is expressed purely with flat fills and solid offset shadows. The only gradient in the codebase is the skeleton shimmer, which is a loading affordance rather than a surface treatment.
